# Cloud Maker

Проект реализует HTTP API для управления виртуальными машинами с помощью QEMU/KVM и libvirt.

**Реализованы дополнительные пункты:**

№1 Приложение, обрабатывающее запросы (app.py)
№6 Восстановление состояния (reconcile())
№11 Скрипт для проверки (test.sh)

## Требования

- Linux с поддержкой KVM (если /dev/kvm не существует, то будет использоваться программная эмуляция)
- Python 3
- QEMU/KVM и libvirt
- `curl` и `jq`

## Установка

```bash
chmod +x setup.sh test.sh
sudo ./setup.sh
sudo apt-get install -y jq
```

## Запуск

Запустите API:

```bash
sudo python3 app.py
```

API будет доступен по адресу `http://127.0.0.1:8080`.

## Проверка

В другом терминале выполните автоматические тесты:

```bash
sudo ./test.sh
```

Тесты проверяют создание, запуск, остановку и удаление виртуальных машин, обработку ошибок и восстановление состояния с помощью `reconcile()`.

Ожидаемый результат:

```text
== Итог: 22 PASS, 0 FAIL ==
OK
```

## Ручная проверка API

Создать ВМ:

```bash
curl -X POST http://127.0.0.1:8080/vms \
  -H "Content-Type: application/json" \
  -d '{"name":"vm1","memory":256,"vcpus":1}'
```

Ожидаемый результат: HTTP 201. Виртуальная машина vm1 должна быть создана и запущена.

Получить список ВМ:

```bash
curl http://127.0.0.1:8080/vms
```

Остановить ВМ:

```bash
curl -X POST 'http://127.0.0.1:8080/vms/vm1/stop?force=1'
```

Ожидаемый результат: HTTP 200. Виртуальная машина должна перейти в состояние shut off.

Запустить ВМ:

```bash
curl -X POST http://127.0.0.1:8080/vms/vm1/start
```

Ожидаемый результат: HTTP 200. Виртуальная машина должна перейти в состояние running.

Удалить ВМ:

```bash
curl -X DELETE http://127.0.0.1:8080/vms/vm1
```

Ожидаемый результат: HTTP 200. Виртуальная машина должна быть удалена из libvirt и из state.json.
